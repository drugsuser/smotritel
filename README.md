# Смотритель

Браузерная игра в PS1-стиле на Three.js. Ты — смотритель маяка.

## Запуск
- **Онлайн:** через GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
- **Локально:** из папки проекта `python -m http.server` → открыть http://localhost:8000  
  (двойной клик по index.html не сработает — браузер блокирует модули с file://)

## Управление
WASD — ходить · мышь — смотреть · E — взять/использовать · F / ЛКМ — предмет в руке · 1–5 — слоты · Esc — пауза

## Где что лежит
| Папка | Что внутри |
|---|---|
| `src/main.js` | запуск, ввод, игровой цикл |
| `src/core/` | движок и PS1-эффекты, звук, настройки, коллизии, общее состояние |
| `src/world/` | материалы/текстуры, небо, море, скалы, маяк |
| `src/player/` | игрок от первого лица |
| `src/ui/` | меню/пауза/настройки, HUD |
| `src/interaction/` | система взаимодействия (E) |
| `src/items/` | реестр предметов, инвентарь, сами предметы |
| `src/props/` | объекты сцены (столик и т.п.) |

## Как добавить предмет
1. Создать `src/items/<имя>.js` (см. `flashlight.js`).
2. Зарегистрировать в `src/items/registry.js`.
3. Положить в мир: `spawnItem('<id>', позиция, поворот)`.

## Тесты
`npm test` (нужен только Node 20+, без зависимостей) — коллизии: стены, стол у перил, дверь против игрока.
Плюс проверка сохранённых настроек. Двигаешь стены/предметы — поправь `SCENE` в `tests/colliders.test.mjs`.
